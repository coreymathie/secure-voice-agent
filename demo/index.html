Safeguard simulator

Play the caller and the model. Every tool call runs through the same make_handler() the phone agent uses: policy gate, step-up verification, velocity limits, PII scrubbing, and a hash-chained audit log. The call-start and keypad panels run the repo's real TwiML builders.

    About the eval suite

    The full call evals (python -m evals.run) aren't run here. They drive the real Lambda handler code, which imports packages that aren't available in the browser (httpx, the Zendesk client, Stripe stand-ins). They run in CI on every push, along with the simulated callers (python -m evals.simulate: 14 scripted multi-turn personas, text-level). The guided scenarios above are the browser-safe subset, and tests/test_demo_engine.py checks their expected outcomes in CI too.

    Built from voice-agent-starter (MIT). Python runs locally in your browser via Pyodide 0.26.4.
